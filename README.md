Conversational AI system powered by Retrieval-Augmented Generation using the Google Gemini 2.5 Flash API. Features session-based memory, a Streamlit web UI, and a CLI interface — built end-to-end with secure API key handling.

> Gemini 2.5 Flash · Session memory · Full-stack deployment

`Python` `Gemini API` `RAG` `Streamlit` `LLM`

---

### [Diabetes Prediction](https://github.com/mus-shaikh)
Binary classification model predicting diabetes onset from clinical features — glucose, BMI, insulin, and age — on the PIMA Indians dataset. Covers full preprocessing, feature importance analysis, and precision-recall evaluation across multiple classifiers.

> Logistic Regression · Random Forest · PIMA dataset

`Python` `Scikit-learn` `Pandas` `Matplotlib`

---

### [Heart Disease Prediction via Clustering](https://github.com/mus-shaikh)
Combines K-Means unsupervised clustering with supervised classification to predict heart disease risk. Patient segments identified through clustering serve as additional features, improving both model interpretability and diagnostic accuracy.

> K-Means segmentation · Hybrid ML approach · Improved interpretability

`Python` `K-Means` `Scikit-learn` `Seaborn`

---

### [Brain Tumor Detection](https://github.com/mus-shaikh)
CNN-based pipeline classifying brain MRI scans as tumour-positive or tumour-negative. Covers image preprocessing, augmentation strategies, and model evaluation designed for reliable medical diagnostic predictions.

> CNN · MRI classification · Image augmentation

`Python` `CNN` `OpenCV` `Deep Learning` `Jupyter`
